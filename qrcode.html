Comment utiliser ce QR code ?

1. Entrez l'URL GitHub Pages de votre expérience AR
(ex: https://votre-pseudo.github.io/nom-du-repo/)

2. Générez et téléchargez le QR code PNG

3. Intégrez-le dans Canva, Word, Illustrator ou directement sur votre flyer

4. L'utilisateur scanne → le navigateur mobile ouvre la page AR → la caméra s'active

⚠️ Important : L'URL doit être en HTTPS pour que la caméra fonctionne sur mobile. GitHub Pages fournit HTTPS automatiquement.
